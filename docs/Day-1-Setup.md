# Day 1 — Ubuntu Workstation Foundation

## Objective

The goal of Day 1 was to establish the foundation for a dedicated local AI workstation capable of running self-hosted AI tools, Docker services, voice interaction systems, and future automation projects.

This workstation was named "Lenny."

---

# Hardware Configuration

## Core Hardware

- AMD Ryzen 9 5950X
- RTX 4070 Ti SUPER
- Ubuntu Linux
- Yeti GX microphone

## Purpose of Build

The system was designed to support:

- Local large language models
- Open WebUI
- Voice pipeline experimentation
- Future J.A.K. assistant development
- Multi-agent AI research
- Long-term infrastructure experimentation

---

# Ubuntu Installation

Ubuntu Linux was selected as the operating system due to:

- strong Docker support,
- AI tooling compatibility,
- Linux automation capabilities,
- and better infrastructure control compared to Windows.

Initial setup included:
- Ubuntu installation
- package updates
- NVIDIA driver setup
- terminal tooling
- Git installation

---

# Early Challenges

Several issues were encountered during initial setup:

- GitHub authentication confusion
- Git identity configuration errors
- Docker workflow learning curve
- uncertainty around Open WebUI networking
- audio pipeline configuration testing
- balancing infrastructure work with documentation discipline

---

# Lessons Learned

Key lessons from Day 1:

- Documentation must happen alongside engineering work
- GitHub integration should be configured early
- Version control is critical for reproducibility
- Infrastructure organization prevents future confusion
- Stable foundations are more important than rushing features

---

# Day 1 Result

By the end of Day 1:

- Ubuntu workstation operational
- GitHub workflow established
- Repository structure created
- Documentation baseline established
- AI workstation foundation successfully deployed
- Secure GitHub CLI authentication configured
