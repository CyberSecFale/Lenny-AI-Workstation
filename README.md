# Lenny-AI-Workstation

Ubuntu-based local AI workstation designed for self-hosted AI operations, voice interaction, automation research, and future local multi-agent development.

---

# Project Goals

This workstation is being developed to:

- Run local large language models (LLMs)
- Support Open WebUI and Dockerized AI services
- Experiment with voice pipelines and conversational assistants
- Develop future J.A.K. operational assistant architecture
- Build repeatable AI infrastructure workflows
- Maintain engineering-grade documentation and troubleshooting logs
